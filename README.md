# Day 2 - Learning about Conditional Statements and Loops in C Programming

This repo contains the practice problems I solved on Day 2 of learning C. Today I spent time getting comfortable with if-else conditions and basic loops (for and while) through some classic beginner logic problems.

### Conditional Statements (if-else)
* *Two numbers equal or not* – Checking if two user inputs match.
* *Positive and Negative* – Finding out whether a number is positive, negative, or zero.
* *Greatest of 2 numbers* – Comparing two numbers to find the larger one.
* *Greatest of 3 numbers* – Finding the largest among three given numbers.
* *Divisibility of 3* – Checking if a number is divisible by 3.
* *Odd & Even* – Checking whether an integer is odd or even.
* *Leap Year* – Verifying if a given year is a leap year.
* *Divisibility by 3, 15, or 20* – Printing hi, hello, or HiHello depending on which number divides the input.

### Loops & Number Problems
* *N natural numbers* – Printing natural numbers up to n.
* *Sum of N numbers in a range* – Taking a start and end value from the user and adding up everything in between.
* *Factors of a number* – Finding all the factors of a given number.
* *Multiplication Table* – Printing the multiplication table for any input number.
* *Prime numbers* – Checking whether a number is prime or not.
* *Count digits in an integer* – Counting how many digits are in a given number.
